OBORY PROGRAMOVÁNÍ

Co chceš tvořit?

Rozbal téma a poznej používané jazyky i krátkou ukázku kódu. Více témat může zůstat otevřených zároveň.

Vývoj her
  • C#
  • C++
  • GDScript (Godot)

Herní programování řeší pohyb postav, pravidla hry, grafiku i zvuk. C# se používá v Unity, C++ v Unreal Engine a GDScript v Godotu.

Hra obvykle běží ve smyčce: načte vstupy hráče, aktualizuje herní svět a vykreslí nový snímek. Programátor propojuje pravidla se scénami, animacemi a fyzikou. Herní engine poskytuje hotové nástroje, ale chování hry je potřeba naprogramovat.

Kde se používá

  • 2D plošinovky, logické hry a mobilní hry
  • 3D světy, simulace a hry pro počítače nebo konzole

Jak začít

Začni malou 2D hrou: pohyb postavy, sbírání mincí a počítadlo skóre. Nejdřív dokonči jednu jednoduchou herní mechaniku.

C# – jednoduchá změna skóre

Základní konzolová ukázka; skutečný herní projekt navíc používá herní engine. 

int skore = 0;
int bodyZaMinci = 10;
skore += bodyZaMinci;
System.Console.WriteLine($"Skóre: {skore}");

Co kód dělá: Proměnná skore začíná na nule. Operátor += přičte body za minci a poslední řádek vypíše nový výsledek.

Umělá inteligence (AI)
  • Python
  • C++
  • JavaScript

AI je širší oblast vytváření systémů, které například rozpoznávají obraz, pracují s textem nebo plánují. Python slouží často k vývoji modelů, C++ k rychlému zpracování a JavaScript k jejich použití ve webu.

Pod AI patří několik přístupů, například systémy pravidel, vyhledávání řešení nebo modely naučené z dat. Vývojář připravuje vstupy a propojuje výstup modelu s aplikací. Výsledek je potřeba ověřovat, protože ani složitý model nemusí vždy odpovědět správně.

Kde se používá

  • Chatboti a pomocníci pro práci s textem
  • Rozpoznávání obrázků, doporučování obsahu a plánování

Jak začít

Vyzkoušej jednoduchého pomocníka s několika předem připravenými odpověďmi. Potom můžeš zkoumat, jak se liší pravidla od modelu naučeného na datech.

Python – odpověď podle pravidel

Jde o jednoduchý systém pravidel, nikoli o naučený model nebo generativní AI. 

odpovedi = {"ahoj": "Ahoj! Jak ti můžu pomoct?"}
zprava = "Ahoj"
odpoved = odpovedi.get(zprava.lower(), "Zkus napsat ahoj.")
print(odpoved)

Co kód dělá: Slovník obsahuje známé otázky a odpovědi. lower() převede vstup na malá písmena a get() vrátí odpověď nebo náhradní text.

Strojové učení
  • Python
  • R
  • Julia

Strojové učení je součást AI. Model hledá vztahy v datech místo toho, aby měl všechna pravidla napsaná ručně. Python nabízí mnoho knihoven, R je oblíbený pro statistiku a Julia pro numerické výpočty.

Typický postup začíná sběrem a čištěním dat. Část dat se použije pro učení a jiná část pro ověření, jak si model poradí s novými příklady. Model může předpovídat číslo, přiřazovat kategorii nebo hledat podobné skupiny. Kvalita dat ovlivňuje výsledek stejně jako zvolený algoritmus.

Kde se používá

  • Odhad ceny nebo budoucí poptávky
  • Rozpoznání spamu a třídění dat do kategorií

Jak začít

Začni malou tabulkou a předpovědí jedné číselné hodnoty. Zkus změnit vstupní data a sleduj, jak se mění výsledek.

Python – naučení jednoduchého lineárního vztahu

Z dvojic čísel odhadneme násobek, který převádí vstup na výstup. Ukázka používá jen základní Python. 

vstupy = [1, 2, 3]
vystupy = [2, 4, 6]
vaha = sum(x * y for x, y in zip(vstupy, vystupy)) / sum(x * x for x in vstupy)
predikce = vaha * 4
print(predikce)  # 8.0

Co kód dělá: Ukázka hledá váhu pro vztah y = váha × x bez konstantního členu. Z dat vyjde váha 2, takže pro vstup 4 předpoví 8. Skutečné modely je nutné ověřit na dalších datech.

Vývoj webů
  • JavaScript
  • TypeScript
  • PHP
  • Python

JavaScript a TypeScript řídí chování webu. PHP nebo Python mohou zpracovávat požadavky na serveru. HTML vytváří strukturu a CSS vzhled; nejsou to programovací jazyky.

Frontend je část webu, kterou uživatel vidí v prohlížeči. Backend na serveru řeší například přihlášení, ukládání dat nebo odpovědi na požadavky. TypeScript rozšiřuje JavaScript o typy a před spuštěním se převádí na JavaScript. U webu je důležitá také přístupnost, bezpečnost a mobilní rozložení.

Kde se používá

  • Prezentační weby, e-shopy a blogy
  • Webové aplikace, formuláře a administrační rozhraní

Jak začít

Nejdřív vytvoř stránku v HTML a CSS. Potom přidej jednu interakci v JavaScriptu, například tlačítko měnící text.

JavaScript – reakce na kliknutí

Ukázka kombinuje HTML a JavaScript. Na tomto webu se zobrazuje jen jako text a nespouští se. 

<button id="pozdrav">Pozdravit</button>
<script>
  document.querySelector("#pozdrav").addEventListener("click", () => {
    alert("Ahoj, světe!");
  });
</script>

Co kód dělá: querySelector() vybere tlačítko podle id. addEventListener() zaregistruje reakci na kliknutí a alert() zobrazí zprávu.

Mobilní aplikace
  • Kotlin
  • Swift
  • Dart

Kotlin se používá pro Android, Swift pro iOS a Dart s Flutterem umožňuje vytvářet aplikace pro více platforem. Vývoj zahrnuje obrazovky, ovládání i práci s daty.

Aplikace musí reagovat na dotyk, různé velikosti obrazovek i změny připojení. Často využívá funkce telefonu, například fotoaparát nebo oznámení. Nativní vývoj cílí přímo na danou platformu; multiplatformní nástroje umožňují sdílet část kódu mezi Androidem a iOS.

Kde se používá

  • Seznamy úkolů, poznámky a kalendáře
  • Mapy, komunikace a aplikace pracující s fotoaparátem

Jak začít

Vytvoř jednu obrazovku s tlačítkem a počítadlem. Postupně přidej uložení hodnoty a přechod na další obrazovku.

Kotlin – text zobrazený v konzoli

Základní funkce Kotlinu. Pro obrazovku aplikace by bylo potřeba také rozhraní Androidu. 

fun main() {
    val uzivatel = "Vít"
    println("Vítej v aplikaci, $uzivatel!")
}

Co kód dělá: fun označuje funkci. val vytvoří hodnotu, která se znovu nepřiřazuje, a $uzivatel vloží její obsah do textu.

Data a databáze
  • SQL (SQLite)
  • Python
  • R

SQL slouží k dotazování nad relačními databázemi. Python a R pomáhají data čistit, analyzovat a zobrazovat v grafech.

Relační databáze ukládá data do tabulek propojených klíči. Dotazy vybírají, filtrují a spojují záznamy. Datová analýza navazuje výpočty a grafy, které pomáhají hledat souvislosti. SQLite je příklad databáze používající SQL, nikoli název samostatného programovacího jazyka.

Kde se používá

  • Ukládání uživatelů, objednávek a výsledků
  • Přehledy, statistiky a vizualizace dat

Jak začít

Navrhni tabulku výsledků a několik záznamů. Vyzkoušej jejich výběr, seřazení a výpočet průměru.

SQL – výběr nejlepších výsledků

Dotaz předpokládá existující tabulku vysledky se sloupci jmeno a body. 

SELECT jmeno, body
FROM vysledky
WHERE body >= 80
ORDER BY body DESC;

Co kód dělá: SELECT určuje sloupce, FROM tabulku a WHERE filtr. ORDER BY seřadí výsledek; DESC znamená sestupně.

Automatizace a skripty
  • Python
  • Bash
  • PowerShell

Skripty zjednodušují opakované úkoly, například práci se soubory, zpracování textu nebo správu počítače. Python funguje napříč systémy, Bash je běžný v Linuxu a PowerShell ve Windows.

Automatizace propojuje malé kroky do opakovatelného postupu. Skript může zpracovat mnoho souborů nebo pravidelně připravit přehled. Při práci je potřeba počítat s chybějícími soubory a jinými chybami. Operace měnící data je vhodné nejdřív zkoušet na kopiích.

Kde se používá

  • Hromadné zpracování souborů a generování reportů
  • Kontrola záloh a správa vývojového prostředí

Jak začít

Napiš skript, který pouze vypíše plánované názvy souborů. Až rozumíš výsledku, přidej skutečnou práci se soubory.

Python – vytvoření jednoduchých názvů souborů

Ukázka pouze vypisuje názvy; žádné soubory nevytváří ani nemění. 

for cislo in range(1, 4):
    nazev = f"report-{cislo}.txt"
    print(nazev)

Co kód dělá: range(1, 4) vytvoří čísla 1, 2 a 3. Cyklus sestaví pro každé číslo název a print() ho vypíše.

Systémy a vestavěná zařízení
  • C
  • C++
  • Rust

Tyto jazyky se používají pro části operačních systémů, ovladače a programy pro malá zařízení. Důležitý je výkon a práce s pamětí; Rust navíc pomáhá předcházet řadě chyb při její správě.

Vestavěný program může běžet na mikrokontroléru s omezenou pamětí. Čte senzory a řídí například motor nebo chlazení. Systémové programování pracuje blízko hardwaru a vyžaduje přesnou správu zdrojů. Podpora konkrétního jazyka závisí také na zařízení a dostupných nástrojích.

Kde se používá

  • Senzory, chytrá zařízení a řízení strojů
  • Ovladače a výkonné systémové nástroje

Jak začít

Začni čtením simulované hodnoty senzoru a rozhodnutím podle limitu. Na skutečné zařízení přejdi až po zvládnutí základů.

C – vyhodnocení naměřené teploty

Teplota je zde zadaná ručně. Na zařízení by ji program načetl ze senzoru. 

#include <stdio.h>

int main(void) {
    int teplota = 28;
    if (teplota > 25) {
        puts("Zapnout chlazení");
    }
    return 0;
}

Co kód dělá: Podmínka if porovná teplotu s limitem. puts() vypíše zprávu, pokud je limit překročen; return 0 ukončí program úspěšně.
