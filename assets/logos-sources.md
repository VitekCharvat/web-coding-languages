# Loga jazyků

SVG obrázky ve složce `logos/` pocházejí z projektu [Devicon](https://github.com/devicons/devicon), verze v2.16.0. Originální soubory jsou stažené beze změny z `icons/<název>/<název>-original.svg`; Bash používá variantu plain.

Licence projektu je přiložená jako `logos/LICENSE-devicon.txt`. Loga identifikují příslušné jazyky a nástroje.

Godot reprezentuje GDScript v prostředí tohoto enginu. Logo SQLite je označené „SQL (SQLite)“, protože SQL nemá jedno společné logo všech databází.

Loga jsou uložená místně, takže se nenačítají ze vzdáleného CDN při návštěvě webu. Každé logo doprovází textový název. Prázdný atribut `alt` zabraňuje dvojímu čtení stejného názvu čtečkou obrazovky.
