## Společný prompt

Use case: ui-mockup. Create one polished raster desktop website mockup, full page visible, flat front view, no device frame. Simple Czech school project about programming languages, feasible with basic HTML and CSS, no effects, gradients, photography or code snippets. Consistent layout: narrow top navigation logo codebase left, info icon and O tématu, code icon and Jazyky right. Spacious hero with large Czech heading Programovací jazyky. Short Czech subtitle and button Prozkoumat jazyky. Below white explanatory section CO TO JE? and Jazyk pro každý nápad. Then Poznejte jazyky with four equal cards Python, JavaScript, Java, C++, small square initials and short Czech descriptions. Simple footer with Homepage, Vít Charvát, Bylo použito AI. Typography like DM Sans and Space Grotesk. Keep readable Czech text, restrained whitespace and straightforward rectangular UI. No table.
