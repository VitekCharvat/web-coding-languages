# Návrhy vzhledu

Tato složka obsahuje obrázkové mockupy školního webu codebase, vytvořené pomocí imagegen.

| Soubor | Popis |
| --- | --- |
| `mockup-01-modry.png` | Neschválená modrá varianta. |
| `mockup-02-zeleny.png` | Neschválená zelená varianta. |
| `mockup-03-fialovy.png` | Neschválená fialová varianta. |
| `mockup-04-puvodni-vzhled.png` | Schválený návrh: tmavě modrá, žlutá, krémová a barevné karty. |
| `mockupy.md` | Palety a prompty prvních tří návrhů. |

Mockupy slouží jako vizuální reference. Nejsou vložené jako obrázek celé stránky do HTML; vzhled je vytvořený v `style.css`. Drobnosti textu a rozložení se mohou lišit. Ukázka kódu ani tabulka nejsou součástí schválené implementace.

## Zadání schváleného návrhu

Jednoduchý celostránkový desktopový mockup českého webu o programovacích jazycích. Navigace s logem codebase a odkazy O tématu a Jazyky. Tmavě modrý úvod a zápatí (#152c3b), žluté zvýraznění (#f4b544), krémový obsah (#fffdf9), světlá šedozelená sekce jazyků (#edf2f0). Nadpis Programovací jazyky., úvodní text a tlačítko Prozkoumat jazyky. Sekce Jazyk pro každý nápad. a čtyři karty Python, JavaScript, Java a C++ s barevnými ikonami a horními okraji. Fonty podobné DM Sans a Space Grotesk. Bez tabulky, ukázky kódu a dekorativní ilustrace.
